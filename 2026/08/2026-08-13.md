  - `vllm/model_executor/models/qwen3_next.py`
  - `vllm/model_executor/models/qwen3_next_mtp.py`

### Summary

**What changed and why**  
This PR fixes a bug in Qwen3Next models where single-token decode with expert parallelism and MoE sequence parallelism produced corrupted output. The root cause was that the model inferred the hidden-state layout from the first tensor dimension, which is ambiguous during TP2 single-token decode. The fix establishes a fixed model-wide sequence-parallel contract: shard once before the decoder stack, all-gather before attention and reduce-scatter after in every layer, keep layer boundaries sequence-parallel, and gather once after the final norm. This removes runtime layout inference and applies to all-MoE Qwen3Next/Qwen3.5 models, while mixed dense/MoE configurations retain the existing layer-local path. MTP implementations are adapted to shard before and gather after direct decoder calls to honor the new contract.

**Technical impact**  
The change refactors the forward pass of Qwen3NextModel, Qwen3NextDecoderLayer, and InternS2MobiusModel to use a deterministic sequence-parallel contract instead of shape-based inference. It introduces a helper function `_should_use_sequence_parallel` to determine when the contract applies, and removes the `_all_gather_hidden_and_residual` helper. The MTP modules now explicitly shard and gather around decoder layer calls. This affects performance and correctness for all-MoE Qwen3Next/Qwen3.5 models with sequence parallelism enabled, and also touches InternS2Mobius which shares the same code path.

**Potential risks**  
The change assumes that all layers in the model have the same `use_attn_reduce_scatter_for_moe` flag, which is enforced by the new `_should_use_sequence_parallel` condition (requires no `mlp_only_layers` and `decoder_sparse_step == 1`). If a configuration violates this assumption, the model may produce incorrect results. The MTP changes add assertions that could fail if hidden_states are not full sequence length before sharding, which might break speculative decoding in edge cases. The removal of the residual chunking in the decoder layer could affect residual stream handling for non-sequence-parallel paths, though the code now always chunks residual when `use_attn_reduce_scatter_for_moe` is true. The change also modifies InternS2Mobius, which may have different requirements, and the impact there is not explicitly tested in the PR.

**Key insights**  
The PR correctly identifies that shape-based layout inference is fragile in distributed settings, especially with small batch sizes. By enforcing a fixed contract, it simplifies the code and removes ambiguity. The approach mirrors the Kimi K3 structure, indicating a consistent design pattern. The MTP adaptation is thoughtful: since MTP bypasses the model forward, it must manually shard and gather to maintain the contract. The PR includes a clear test plan with before/after outputs demonstrating the fix, and it explicitly scopes the change to all-MoE models to avoid breaking mixed-layer configurations.
